## A command you save once and never type again

1. Click **TM** in the bottom-left corner of the window.
2. Choose **Add new command**.
3. Type a name, for example `Update from main`.
4. Type the command, for example `git pull --rebase origin main`.

That is all. From now on: click **TM**, pick `Update from main`, and the command runs in the terminal.

| You see in the status bar | What it is | A click |
|---------------------------|------------|---------|
| `TM` | your saved commands | opens the list |
| `Last: Update from main` | the command you ran last | runs it again |
| `🕒 Build in 14m` | a scheduled command | shows your schedules |

In the list, type a few letters to filter and press **Enter** to run.

Your commands are saved in your own settings, so you have them in every project.
