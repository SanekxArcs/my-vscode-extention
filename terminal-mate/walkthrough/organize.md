## The small buttons on a row

Open the list and point at a command. These buttons appear on the right:

| Button | What it does |
|--------|--------------|
| ↑ ↓ | moves the command up or down |
| 🕒 | runs the command later, or again and again |
| ✏ | opens the edit menu |
| 🗄 | archives the command: hides it without deleting it |
| 🗑 | deletes the command (asks first) |

The list stays open while you move or archive, so you can click several times.

## The edit menu (the pencil)

| Item | What it changes |
|------|-----------------|
| Title | the name in the list |
| Command | what runs |
| Working directory | the folder the command runs in |
| Group | the heading the command is shown under |
| Duplicate | makes a copy that you can change |
| Keyboard shortcut | gives the command its own key |

## Archive

Archived commands are at the bottom of the list under **Archive**. Open it to bring a command back or to delete it for good.
