## Run with options

Click the terminal button on a row.

**Arguments.** Type what should come after the script, for example `--watch`. RunMate remembers the last five for each script.

**Env file.** Choose `.env.local`, `.env.staging` or any other env file of the project. Its variables are loaded before the script starts. RunMate remembers the choice for that script and shows it on the row, until you choose **No env file**.

**Another shell.** Run once in Git Bash, PowerShell, bash, zsh and so on, without changing your settings.

To repeat the last run with the same options: **RunMate: Run Last Script Again** in the Command Palette. Give it a keyboard shortcut if you use it a lot.
