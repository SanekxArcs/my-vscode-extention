## Your scripts are buttons

Look at the bottom-left corner of the window.

| You see | What it is | A click |
|---------|------------|---------|
| `▶ dev` | a script | runs it |
| `⏹ dev` (orange) | a script that is running | stops it |
| `✖ dev` (red) | a script that failed | runs it again |
| `📦 web` | a project, when your repository has several | shows its scripts |
| `...` | everything else | opens the script list and the settings |

The script list also opens with **Ctrl+Alt+Q**. Type to filter, press **Enter** to run.

RunMate reads `package.json` scripts, and also Deno tasks, Makefile targets and just recipes.
